    Le cadastre s'affiche à partir du 1:10 000. Cliquez sur une parcelle pour obtenir sa fiche de renseignements, ou sur un arbre pour sa fiche d'inventaire.

    Fiche de renseignements

    Zoomez sur la carte puis cliquez sur une parcelle, ou recherchez une référence cadastrale (par exemple ).

    La fiche croise la parcelle (API Carto de l'IGN) avec le zonage du PLU, les prescriptions, les informations, les servitudes et les zonages naturels de la base intercommunale. Équivalent ouvert d'une fiche Cart@DS ou Arcopole.
